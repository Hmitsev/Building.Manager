# Building.Manager V1

Streamlit приложение за управление на етажна собственост с Neon PostgreSQL и Render.

## Включени функции

- роли: домоуправител, касиер, съсед;
- регистрация с одобрение;
- апартаменти, офиси, магазини, гаражи и паркоместа;
- такса вход: 6 EUR на пълнолетно лице;
- индивидуален годишен ФРО;
- избор на няколко месеца и кошница;
- банкови заявки и ръчно плащане;
- разходи и каси;
- архив и Excel отчет;
- динамичен новинарски банер;
- заявки за промяна на броя живущи;
- история и административен дневник.

## 1. Качване в GitHub

Създайте repository `Building.Manager` и качете цялото съдържание на папката. Не качвайте собствен `.env` или `secrets.toml`.

## 2. Neon

Създайте Neon project и копирайте PostgreSQL connection string с `sslmode=require`. Не е необходимо ръчно изпълнение на SQL. Приложението създава таблиците автоматично при първо стартиране.

## 3. Render

Създайте нов Web Service от GitHub repository или използвайте `render.yaml`.

Build command:

```text
pip install -r requirements.txt
```

Start command:

```text
streamlit run app.py --server.address 0.0.0.0 --server.port $PORT
```

Добавете Environment Variables:

```text
DATABASE_URL=<Neon connection string>
ADMIN_EMAIL=<вашият администраторски имейл>
ADMIN_PASSWORD=<силна начална парола>
APP_SECRET=<дълга случайна стойност>
BUILDING_IBAN=<IBAN на етажната собственост>
BUILDING_PAYEE=<име на получателя>
```

## 4. Първи вход

При първото стартиране се създава домоуправителят от `ADMIN_EMAIL` и `ADMIN_PASSWORD`. Влезте с тези данни, отворете „Админ панел“ и добавете апартаментите.

## 5. Регистрация на съседите

След добавяне на апартаментите съседите могат да се регистрират. Регистрацията остава „pending“, докато домоуправителят я одобри.

## Важно преди реално използване

- сменете началната администраторска парола;
- не публикувайте Neon connection string в GitHub;
- въведете правилния IBAN;
- първо тествайте с тестов апартамент и тестови плащания;
- историческите данни от стария Excel не са включени автоматично в този starter package. Те трябва да преминат през отделен контролиран импорт.
